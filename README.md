# alontayarcom
Alon Tayer אלון תייר

אתר האמן. HTML/CSS/JS פשוט, ללא תלות ב-build, מתאים ל-GitHub Pages.

## מבנה
- `index.html` - דף הבית
- `music.html` - דף מוזיקה עם גריד כל האלבומים
- `js/albums.js` - **מקור אמת יחיד** לרשימת האלבומים (שם, עטיפה, קישור להאזנה)
- `js/playlist.js` - רשימת קבצי mp3 לרדיו הרציף (ראה `songs/README.md`)
- `songs/` - קבצי mp3 לרדיו (עוד לא הועלו)
- `images/album-placeholder.svg` - עטיפת אלבום זמנית, עד לצאת האלבום

## דברים שצריך לעדכן בעתיד
1. **קישור ההאזנה**: בקובץ `js/albums.js`, עדכן את `link` לקישור lnk.to האמיתי.
2. **לוגו**: כרגע השם "אלון תייר" כתוב בטקסט (פונט Arial). כדי להחליף בלוגו, ערוך את `<h1 class="logo">` ב-`index.html` והחלף ב-`<img>`.
3. **רשתות חברתיות**: הקישורים לטיקטוק/יוטיוב/אינסטגרם הם placeholder (`#`) בכל אחד מהקבצים `index.html` ו-`music.html` - צריך לעדכן לקישורים האמיתיים.
4. **שירי רדיו**: העלה קבצי mp3 לתיקיית `songs/` ורשום אותם ב-`js/playlist.js`.
5. **אלבומים נוספים**: הוסף אובייקט חדש למערך `ALBUMS` ב-`js/albums.js` - הוא יופיע אוטומטית גם בדף הבית (כאלבום האחרון) וגם בגריד של דף המוזיקה.

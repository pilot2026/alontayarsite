# שירי הרדיו

שים כאן קבצי mp3, ואז הוסף את השם שלהם ל-`js/playlist.js` (במערך `SONGS`).

לדוגמה, אם העלית קובץ בשם `song1.mp3`, תוסיף בקובץ `js/playlist.js`:

```js
const SONGS = [
  "songs/song1.mp3",
  "songs/song2.mp3",
];
```

הנגן ינגן את השירים ברצף ובלולאה אינסופית, בסדר אקראי בכל הפעלה, ואין כפתורי דילוג קדימה/אחורה.
